One complete story in exactly six words.

## The story

> Sold the map. Kept the treasure.

A seller parts with the map — and keeps the prize. Who bought it, what the treasure is, and what happens when the buyer follows a map to nothing: the reader fills all of that in.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only, no network, deterministic) writes the story above to `entry.txt` in the output directory, where the gate reads it.
